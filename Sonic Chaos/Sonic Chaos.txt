Sonic Chaos Master System Disassembly By RF (AKA Amber Davis)
Yet another disassembly from me. Special thanks to Hivebrain for his notes, which are bellow.I hope to finish this someday.
For now, i'm not sure if anyone would find this useful, but maybe someone will.   
Screenmode Flags:
$1- Title Card Sequence
$7- Title Screen
$6- Intro Sequence
$4- Demo 
Button Id's
$00- Down
$01- Up
$02- right
$03- left
Most RAM addresses are still the same as Sonic 2, since this is Aspect's engine. :V They are bellow (not all are listed):
$D137- Controller 1 input 
$D516- Horizontal Velocity (which is always stored as a word, for obvious reasons.)
$D518- Vertical Velocity
$D500- Objects (Whether it be Sonic/Tails. $01-Sonic $02 Tails.) Other objects are located after Tails. 
$D503- object state (setting the bitfield to 0 always sets the player in the air, and
setting this to 1 sets the destroy on collision flag. Reseting bitfield 1 nulls out the
destroy on collision flag, which of course hurts the player.)
